# 743 City Barbershop

## Project Description

743 City Barbershop is a multi-page website designed to provide customers with information about the barbershop, its services, prices, gallery, and contact details.

The website is designed to provide clear information, simple navigation, and a user-friendly experience for customers using desktop and mobile devices.

## Published Website

**Live Website:**

https://br737-code.github.io/743-City-Barbershop/

## Website Pages

The website includes the following pages:

* **Home** – Introduction to 743 City Barbershop and key information for customers.
* **About** – Information about the barbershop.
* **Services** – Details of available barbering services and prices.
* **Gallery** – Images showing the barbershop and hairstyles.
* **Contact** – Contact information and a way for customers to get in touch.

## Development

The website was developed using **HTML5 and CSS3/modern CSS** in Visual Studio Code.

CSS was used to control the visual presentation, spacing, colours, typography, forms, navigation, and page layouts. Modern CSS features such as **Flexbox, `gap`, `border-radius`, and hover effects** were used to improve the layout and user experience.

Git was used to track the development process and maintain a history of changes. GitHub was used to store the source code and project assets.

The completed website was published using GitHub Pages.
