# 743 City Barbershop

## Project Description

743 City Barbershop is a website designed to provide customers with information about the barbershop, its services, prices, gallery, and contact details. The website is designed to be simple, clear, and easy to navigate on both desktop and mobile devices.

## Website Pages

The website includes the following pages:

* **Home** – Introduction to 743 City Barbershop and key information for customers.
* **About** – Information about the barbershop.
* **Services** – Details of available barbering services and prices.
* **Gallery** – A collection of images showing the barbershop and hairstyles.
* **Contact** – Contact information and ways for customers to get in touch.

## Technologies Used

* HTML5
* CSS3
* Visual Studio Code
* Git
* GitHub

## Project Features

* Responsive website layout
* Navigation menu between pages
* Service and pricing information
* Image gallery
* Contact information
* Accessible and user-friendly page structure

## Development

The website is developed using HTML5 and CSS3 in Visual Studio Code. Git is used to track changes throughout the development process, and GitHub is used to store the project repository.
